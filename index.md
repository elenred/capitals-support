# Столицы / World Capitals — Support

**Столицы (World Capitals)** — приложение для изучения столиц мира: карточки, викторины и прогресс по континентам. Работает полностью офлайн, без аккаунтов и рекламы.

**World Capitals** is an app for learning the capitals of the world: flashcards, quizzes, and per-continent progress. It works fully offline, with no accounts and no ads.
